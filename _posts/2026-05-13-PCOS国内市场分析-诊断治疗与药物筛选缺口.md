> 结论先行：
> 1. **患者端**：诊断缺口是「显性、易追」，治疗缺口是「隐性、难填」。短期内 AI 诊断辅助＞新药。
> 2. **科研端**：国内不缺通用 HTS / CADD 能力（药明、康龙、晶泰、英矽），缺的是 **PCOS-specific 的细胞/类器官模型 + 通路靶点共识**。
> 3. **前端（诊断/患者管理）盈利更快**；**后端（药物筛选/开发）天花板更高**，但风险调整后 NPV 不一定更大。
> 4. **Vibe coding 难度**：Frontend ≪ Backend。前端 1 人 6 个月能跑 MVP；后端纯软件部分可 vibe，但没有湿实验数据 = 没有壁垒。

## 一、PCOS 国内市场盘子

| 指标 | 数据 |
|---|---|
| 育龄女性 PCOS 患病率 | 5.6%–10%（Rotterdam 标准），高发于 18–35 岁 |
| 患者基数（中国） | 约 1500 万–3000 万 |
| 已确诊比例（估算） | < 30%，三四线城市更低 |
| 中位确诊延迟 | 2–4 年（从首次月经异常到拿到诊断书） |
| 共病 | 2 型糖尿病风险 ↑4 倍、子宫内膜癌 ↑2.7 倍、抑郁/焦虑 ↑3 倍、不孕约 40% |
| 现金支付意愿 | 备孕周期女性 > 月经管理用户 > 抗雄/减重用户 |

> 这是一个「大病种、被严重低估」的市场。妇科肿瘤、子宫肌瘤、子宫内膜异位症都有头部上市公司，唯独 PCOS 没有专科龙头——窗口期还在。

## 二、患者端：诊断缺口 vs 治疗缺口

### 2.1 诊断缺口（显性、可被工具替代）

| 缺口 | 表现 |
|---|---|
| **认知** | 患者常把月经不调、痘痘、多毛归因于"体质"，不就医 |
| **路径** | 妇科 / 内分泌科 / 生殖中心三个入口分散，医生间转诊弱 |
| **标准** | Rotterdam 2003 / AES 2009 / NIH 1990 三套标准，基层医生执行参差 |
| **检查** | AMH、游离睾酮、SHBG、HOMA-IR 在县市级医院不齐；超声依赖操作者 |
| **解读** | 报告拿到手，但「胰岛素曲线倒 V 字」「LH/FSH 比值 > 2」患者读不懂 |
| **随访** | 复诊间隔 3–6 个月，期间没有结构化的症状/激素/生活方式记录工具 |

**这是一个"信息+工具"的缺口，不是"药物"的缺口。** AI agent + 报告 OCR + 症状追踪 + 教育内容就能填掉 70%。Cyster 现在的形态正好对着这个缺口打。

### 2.2 治疗缺口（隐性、靠工具填不上）

现有疗法全部是对症（symptomatic），没有一个直接打 PCOS 病因——因为病因还没共识。

| 用药 | 适应症 / 作用 | 主要痛点 |
|---|---|---|
| 短效口服避孕药（达英-35、优思明、优思悦） | 调经、抗雄 | 停药即复发；血栓风险；不能用于备孕 |
| 二甲双胍 | 改善胰岛素抵抗（PCOS 多为说明书外用） | 胃肠道反应；不能直接降雄；体重下降有限 |
| 螺内酯 | 抗雄激素，多毛/痤疮 | 月经不规则、高钾血症 |
| 来曲唑 / 克罗米芬 | 促排卵（备孕） | OHSS 风险、多胎；只解决"排卵"不解决"PCOS" |
| 中成药（苍附导痰丸、补肾活血方等） | 调经、改善 IR | 证据等级低、剂量个体化差 |
| 生活方式（减重 5–10%） | 改善代谢和排卵 | 依从性差，PCOS 减重比普通人难 3–5 倍 |

**国内外 PCOS 创新药管线（截至 2026 Q1）极其稀薄：**

| 公司 | 候选物 | 机制 | 阶段 | 备注 |
|---|---|---|---|---|
| Spruce Biosciences | Tildacerfont | CRF1 拮抗剂 | Ph2 (PCOS) | 主线是 CAH，PCOS 是扩展 |
| Bayer | Elinzanetant | NK1/3 拮抗剂 | 已上市（VMS） | 学术界讨论延伸到 PCOS |
| Crinetics | Atumelnant | ACTH 受体拮抗剂 | Ph2 | CAH 为主 |
| 国内（恒瑞、信达、再鼎等） | — | — | — | 暂无在研 PCOS-as-primary 的项目 |
| 学术界早期 | Anti-AMH mAb、Kisspeptin 激动剂、INSL3 通路 | 多通路 | 临床前 | 离 IND 还有 3–5 年 |

> **关键判断**：治疗缺口虽然真实存在，但要 8–12 年才会被填上。患者「现在」的痛点更多是「有药但不知道怎么用、怎么追踪效果」，而不是「无药可用」。

### 2.3 患者端结论

> **短期（0–3 年）：诊断/管理端的市场容量 > 治疗端**。
> 治疗端的钱在 5–10 年后才会大规模出现，而且大概率被外资+恒瑞/翰森这类大药企吃掉。

## 三、医生/科研端：是否缺小分子 + mAb 筛选平台？

不缺通用筛选能力，缺的是「PCOS 把通用筛选用起来的 know-how」。

### 3.1 国内通用筛选能力（不缺）

| 类型 | 头部玩家 | 状态 |
|---|---|---|
| 小分子 HTS / 虚拟筛选 | 药明康德、康龙化成、维亚生物、皓元医药 | 成熟，开放接单 |
| 抗体发现（噬菌体/酵母展示/单 B 细胞） | 药明生物、信达、君实、和铂医药 | 成熟 |
| AI 药物发现 | 晶泰科技、英矽智能（Insilico）、深势科技、剂泰、华深智药 | 活跃，估值百亿级别 |
| 类器官 | 丹望医疗、艾名医学、华夏源、科济药业 | 主要做肿瘤，妇科类器官早期 |
| 靶点验证 / 表型筛选 | 各大 CRO | 成熟 |

### 3.2 PCOS-specific 缺口（真空地带）

| 缺口 | 影响 |
|---|---|
| **缺好的动物模型** | DHT/DHEA 诱导小鼠只复现高雄+不排卵，复现不了胰岛素抵抗+代谢综合征+心理症状全表型 |
| **缺卵巢类器官 / 颗粒细胞–卵泡膜细胞共培养体系** | 通路读出（CYP17A1、AR、AMH 信号）没有标准化 |
| **缺 PCOS 患者来源 iPSC 库** | 没办法做大规模 patient-derived screening |
| **缺纵向真实世界数据** | 无法做病人分型（A/B/C/D 四表型 + 代谢/生殖/心理三轴） |
| **缺靶点共识** | AMH、Kisspeptin、INSL3、GDF-15、IL-22、AR、PPAR-γ —— 每个实验室押一个，重复性差 |

> **科研端真正稀缺的不是"能跑筛选的机器"，而是"知道筛什么、用什么 assay 筛、谁的细胞模型可信"。**

### 3.3 科研端结论

> 直接做"PCOS 小分子 + mAb 筛选公司"是错位竞争：你打不过药明 + 晶泰的通用平台，又拿不到 pharma 的订单（因为 PCOS 不是大药企的优先适应症）。
>
> 正确切法是**做 PCOS-specific 的"数据/模型/通路"基础设施**（类器官 + 真实世界数据 + AI 病人分型），然后把这些卖给 pharma / CRO 做 partnership。

## 四、前端（诊断）vs 后端（药物开发）盈利对比

| 维度 | Frontend：诊断 / 患者管理 / DTx | Backend：药物筛选 / 新药开发 |
|---|---|---|
| **TAM** | C 端 3000 万患者 × ARPU 200–2000 元/年 = 60–600 亿；B 端医生 SaaS 5–20 亿 | 单个 FIC 全球峰值销售 10–50 亿美金；国内市场被医保压价后约 1/3–1/5 |
| **启动资金** | 50 万–5000 万 RMB | 5000 万–10 亿 RMB 起，到 NDA 总投入 5–30 亿 |
| **时间到现金流** | 6–18 个月 | 8–12 年 |
| **成功率** | 商业化失败率 ~70%，但不归零 | 临床 Ph1→上市 整体 ~10%，PCOS 这种异质性大的适应症可能更低 |
| **回报倍数** | 3–15× | 0× 或 100–1000× |
| **风险调整后 NPV（粗估）** | 正期望值，~$5–30M 量级 | 期望值正，但方差极大，~$50–300M ± 巨大置信区间 |
| **退出方式** | 并购（互联网医疗、药企数字化部门）、IPO（港股 18A、纳斯达克）、被生态收编 | License-out、被大药企并购、独立 IPO |
| **监管** | 健康咨询：低；AI 诊断辅助：NMPA 二类/三类器械 | IND / NDA / 国际多中心 |
| **支付方** | C 端订阅 + 电商联动 + B 端医院/药企 SaaS | 医保 + 商保 + 自费；国内集采+谈判压价 |
| **网络效应** | 强：数据飞轮、医生–患者双边 | 弱：药就是药 |
| **可被 AI 加速程度** | 高（前端 + 后端 + agent + RAG 都受益） | 中（AI 药发只是流程的一环，湿实验是瓶颈） |

**短期（0–3 年）：Frontend 盈利机会明显更大**
- 现金流早、估值方法清楚（SaaS / 互联网医疗倍数）
- Cyster 这种形态已经验证：丁香医生、好大夫、橙医生、Flo（海外）、Clue（海外）走通了

**长期（5–15 年）：Backend 一旦成功，回报远超 Frontend**
- 全球第一个 PCOS-as-primary FIC 是几十亿美金量级的事
- 但 95% 概率拿不到这张票

**风险调整后**：Frontend 期望值更稳，Backend 期望值上限更高但方差吓人。

## 五、Vibe Coding 难度对比

### 5.1 Frontend（Cyster 类患者平台）：极适合 vibe coding

**能 vibe 出来的部分（≥ 90%）：**
- 聊天界面、报告上传、症状追踪、社区、医生工作站 → 纯前端 + 后端 CRUD
- AI agent：直接调 Claude / GPT / Qwen / 文心 API，做症状问诊、报告解读、生活方式建议
- 报告 OCR：通义 / GPT-4V / Claude vision 直接出结构化 JSON
- 推荐系统：基于规则 + 简单 ML 就够用
- 用户管理、支付、订阅：成熟模板

**vibe 不出来的部分（10%）：**
- 医疗器械级别的诊断准确性（需要临床验证 + NMPA 注册）
- 数据合规（《个人信息保护法》《数据出境安全评估办法》）
- 医保对接、电子处方流转（需牌照）
- 高质量医学内容审核（要医生团队）

**1 人 6 个月 MVP 完全可行。Cyster 已经证明了这一点。**

### 5.2 Backend（药物筛选）：vibe coding 做不出壁垒

**能 vibe 出来的部分（30–50%）：**
- 分子对接 pipeline：串 AutoDock Vina / DiffDock / Boltz-2，前端做可视化 → 1 个月能搭
- QSAR / ADMET 预测：用 ChEMBL + DeepChem / RDKit 训模型 → 几周
- 蛋白结构预测：调 AlphaFold3 / ESMFold API → 几天
- 虚拟筛选平台：化合物库 × 靶点 × docking → 1–2 个月有 demo
- AI 药物发现 SaaS 给 pharma 用：dashboard、任务调度、报告 → 3–6 个月

**vibe 不出来的部分（50–70%，且是核心壁垒）：**
- **湿实验数据**：化合物合成、细胞实验、动物实验、PK/PD —— 这是钱和时间，不是代码
- **靶点选择 know-how**：押错靶点 = 全部白做
- **PCOS-specific 模型**：自己建卵巢类器官 / patient-derived iPSC 体系
- **GLP/GMP 合规实验室**：硬件 + 人 + SOP
- **化合物库的真实价值**：你能调用的库 vs 药明 200 万 + 化合物库的差距
- **数据获取**：ChEMBL 是公开的，pharma 真正值钱的是内部 SAR 数据，拿不到

**纯软件部分 1 人 1 年能搭出来，但没有湿实验数据 = 给 pharma 没人买。**

### 5.3 难度结论

| 维度 | Frontend | Backend（纯软件） | Backend（含湿实验） |
|---|---|---|---|
| 可 vibe 比例 | 90%+ | 50% | 10–20% |
| 1 人 6 个月可达 | MVP + 部分商业化 | 一个 demo 平台 | 完全不可能 |
| 资本要求 | 低 | 中 | 极高 |
| 护城河形成时间 | 12–24 个月（数据飞轮） | 不会形成 | 3–8 年 |

## 六、综合建议（针对 Cyster 现状）

### 6.1 不要犹豫，先把 Frontend 做深做透（0–24 个月）

- **核心叙事**：从「咨询平台」升级到「PCOS 数字健康管理 OS」
- **三个支柱**：
  1. **AI 报告解读 + 症状追踪**（C 端订阅，9.9–39 元/月）
  2. **药物 / 复诊 / 检查依从性管理**（联动药店、第三方检验、远程问诊抽成）
  3. **医生工作站 SaaS**（一年几千块，下沉到二级医院妇科/生殖中心）
- **数据资产**：用户的「症状 + 激素 + 超声 + 治疗反应」纵向数据是稀缺资产，是后续一切想象力的来源

### 6.2 中期：用 Frontend 的数据资产去做 Backend 赋能（2–5 年）

- 当你手上有 10 万 + 真实世界 PCOS 患者纵向数据：
  - **Patient stratification**（A/B/C/D 四型 × 代谢/生殖/心理三轴）卖给 pharma 做临床入组优化
  - **RWS / RWE 合作**：给 CRO / pharma 做真实世界研究
  - **DTx 申报**：把 Cyster 升级为 NMPA 二类 / 三类医疗器械，撬开医保
- 这是 Verily、Evidation、Akili 走过的路

### 6.3 长期：考虑 PCOS-specific 的"基础设施型"Backend，不要 me-too 做筛选公司（5–10 年）

- 错位竞争点：**类器官 / 病人来源细胞 / 通路报告基因 / 真实世界数据 + 病人分型**
- 商业模式：**license-in 早期候选物 + 用自己的数据帮 pharma 定位临床**，而不是从 0 做新药
- 如果非要做新药，**找一个已经有 Ph1 安全性数据的分子**，PCOS 是它的 indication expansion，不要从头烧靶点

### 6.4 最具杠杆的一招：Frontend 的"医生工作站"模式

- C 端获客贵、留存难、付费率低（中国互联网医疗永恒的痛）
- B 端：把 Cyster 的「AI 报告解读 + 症状追踪 + 病人管理」打包成「PCOS 专科医生工作站」
- 一年订阅 3000–8000 元，覆盖二级以下医院妇科 / 生殖中心
- 同时给医生开「分级诊疗下沉端口」，把患者从医生处导回 Cyster C 端
- 这是 PCOS 版的「医联 + 医脉通 + 太美医疗」专科亚版

## 七、一句话总览

> **患者最缺的不是新药，是「能听懂、能管好、能跟踪」的工具。**
> **医生最缺的不是筛选机器，是「PCOS 真实世界数据 + 病人分型」。**
> **盈利机会上：前端短期吃肉，后端长期博命。**
> **Vibe coding 难度：前端可 vibe，后端的壁垒在湿实验，vibe 不出来。**
>
> **结论：Cyster 现在的方向是对的。把前端的「数据飞轮」转起来，5 年后你才有资格谈后端。**
